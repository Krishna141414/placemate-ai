# Kairos Cloud Labs - Cloud Support Associate

(Fictional sample company.)

## About the company

Kairos Cloud Labs is a managed cloud provider. Its customers are mid-sized companies that want someone else to run their servers, backups and monitoring.

## Role

Cloud Support Associate. Associates handle customer tickets, debug server and network problems, and write small automation scripts. The role includes rotational shifts, with night shifts about one week in four.

## Compensation

CTC is 7 LPA to 9 LPA, which includes a shift allowance. This is a Standard category company under the placement policy. Location is Chennai.

## Eligibility

- Branches: CSE, IT and ECE.
- Minimum CGPA: 7.5.
- Active backlogs: at most 1.
- Batch: 2027 graduates.

## Selection process

1. **Online Assessment (75 minutes).** Multiple-choice questions on Linux commands, networking (TCP/IP, DNS, HTTP, subnetting) and operating systems, plus one scripting problem in Python or Bash.
2. **Technical Interview (45 minutes).** Troubleshooting scenarios such as "a website is slow, how do you find out why?", Linux file permissions, processes, and what happens when you type a URL into a browser.
3. **Managerial Round (30 minutes).** Handling an angry customer, prioritising tickets, and comfort with shifts.
4. **HR Interview (15 minutes).**

## Skills they look for

Required: Linux, networking, AWS basics, Python. Good to have: Docker, Bash scripting.

## Important dates

- Apply by: 12 December 2026.
- Online Assessment: 16 December 2026.
- Interviews: 18 December 2026.

## Notes

The company pays for one AWS certification attempt in the first year. An AWS Cloud Practitioner certificate is not required but helps in shortlisting.
