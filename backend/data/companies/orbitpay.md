# OrbitPay Fintech - Backend Engineer

(Fictional sample company.)

## About the company

OrbitPay Fintech provides a payment gateway and payout service for online sellers. Money movement means every change is reviewed twice and tested heavily.

## Role

Backend Engineer in the payouts team. Engineers build and maintain REST services, write SQL against large transaction tables and take part in incident reviews.

## Compensation

CTC is 10 LPA to 12 LPA. This is a Dream category company under the placement policy. Location is Mumbai.

## Eligibility

- Branches: CSE, IT and ECE.
- Minimum CGPA: 8.0.
- Active backlogs: at most 1, which must be cleared before the offer letter is issued.
- Batch: 2027 graduates.

## Selection process

1. **Online Coding Test (90 minutes).** Two coding problems (medium difficulty) and 15 multiple-choice questions on SQL, operating systems and networking.
2. **Technical Interview (60 minutes).** One problem on hash maps or heaps, SQL joins and transactions (ACID, isolation levels), and how a REST API should handle retries and idempotency.
3. **System Design Basics Round (45 minutes).** Design a simple wallet or a notification service. Interviewers look for clear thinking about APIs, tables and failure cases, not for buzzwords.
4. **HR Interview (20 minutes).**

## Skills they look for

Required: Java, SQL, REST API, data structures. Good to have: microservices, Redis. Python is accepted in the coding test, but the team's code is in Java.

## Important dates

- Apply by: 8 December 2026.
- Online Coding Test: 10 December 2026.
- Interviews: 14 December 2026.

## Notes

A background verification is done before joining. There is no service agreement.
