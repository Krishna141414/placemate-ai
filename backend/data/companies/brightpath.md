# Brightpath Edtech - Frontend Developer

(Fictional sample company.)

## About the company

Brightpath Edtech runs a learning app for school students in classes 6 to 10. The product team is small, about 40 people, and ships to the web and to mobile from one React codebase.

## Role

Frontend Developer. The work is building lesson screens, quizzes and teacher dashboards in React, and working closely with designers. Accessibility and performance on low-end phones are part of the job.

## Compensation

CTC is 6 LPA to 7.5 LPA. This is a Standard category company under the placement policy. Location is Bengaluru, with two days a week of remote work.

## Eligibility

- Branches: CSE and IT.
- Minimum CGPA: 6.5.
- Active backlogs: at most 1.
- Batch: 2027 graduates.

## Selection process

1. **Take-home Assignment (48 hours).** Build a small quiz page in React from a given design: a list of questions, a timer and a results screen. Code is judged on structure, not on visual polish alone.
2. **Technical Interview (60 minutes).** A review of the assignment code, then JavaScript fundamentals (closures, promises, the event loop), CSS layout with flexbox and grid, and React state and effects.
3. **Culture Round (30 minutes).** A conversation with the product head about how the candidate learns and works in a team.

## Skills they look for

Required: JavaScript, React, HTML, CSS. Good to have: TypeScript, Git.

## Important dates

- Apply by: 1 December 2026.
- Assignment released: 3 December 2026, to be submitted by 5 December 2026.
- Interviews: 8 December 2026 (online).

## Notes

There is no aptitude test. A link to a deployed project or a GitHub profile is asked for in the application form.
