# Veltrix Systems interview experience - Harini V. (CSE, 2026 batch, selected)

(Fictional sample write-up.)

## Online Coding Test

Three problems in 120 minutes. Mine were: an easy array question (rotate an array by k), a medium graph question (number of connected groups of warehouses, which is counting components with BFS or union-find), and a hard dynamic programming question on minimum cost to split a delivery route. I solved the first two completely and got partial marks on the third. Two fully solved problems was the cut-off; 14 students went through.

## Technical Interview 1

Two problems on a shared editor: find the k-th largest element in a stream (min-heap of size k) and the lowest common ancestor in a binary tree. The interviewer cared a lot about edge cases and asked me to dry-run my code on an input he chose.

## Technical Interview 2

Object-oriented design of a parking lot: classes, relationships and how to extend it for electric vehicle charging slots. Then DBMS: what an index is, when an index makes writes slower, and the difference between the READ COMMITTED and SERIALIZABLE isolation levels.

## Hiring Manager Round

A deep-dive into my final-year project and one basic system design question: how would you design a service that tracks the live location of 10,000 delivery vans? He was happy with a simple design as long as I could say where it would break.

## Tips

- Graphs and dynamic programming decide the coding test.
- Practise low-level design at least five times before the drive.
- Think aloud. Silence is read as being stuck.
