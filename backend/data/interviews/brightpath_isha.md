# Brightpath Edtech interview experience - Isha G. (CSE, 2026 batch, selected)

(Fictional sample write-up.)

## Take-home Assignment

We got a design file and 48 hours to build a quiz page in React: a question list, a countdown timer and a results screen. I spent the first evening only planning components and state. I kept the quiz state in one reducer and wrote a custom hook for the timer. I also added keyboard navigation and a README explaining my decisions, and the interviewer later said the README is what got me shortlisted.

Things people lost marks for, according to the feedback email: one giant component, no handling for the timer reaching zero, and copying a UI library without understanding it.

## Technical Interview

The first 25 minutes were a code review of my assignment. "Why is this state here and not in the parent?" "What re-renders when the timer ticks?" Then JavaScript: closures with a counter example, the output order of a snippet mixing setTimeout and promises (the event loop question), and the difference between == and ===.

CSS: centre a div both ways, the difference between flexbox and grid, and how to make a layout work on a small phone. React: useEffect dependency arrays, keys in lists, and controlled inputs.

## Culture Round

A relaxed talk about how I learn new things and a project I was proud of.

## Tips

- Treat the assignment like real work: small components, clear names, a README.
- Know why your code re-renders.
- There is no aptitude test here, so spend that time on JavaScript fundamentals.
