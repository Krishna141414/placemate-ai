# Nimbusware Technologies interview experience - Fathima S. (IT, 2026 batch, selected)

(Fictional sample write-up.)

## Online Assessment

I found the coding section harder than the aptitude. My two problems were a sliding window question (longest substring without repeating characters) and a simple one on counting word frequency. I fully solved the second and passed most test cases on the first, and still got shortlisted, so partial solutions do count.

## Technical Interview

My interviewer was friendly and started with Python basics: the difference between a list and a tuple, what a dictionary does internally, and what a decorator is. Then she asked me to design the tables for a library management system and write two queries on them: books currently issued, and members with more than three overdue books.

For data structures I was asked to find the middle of a linked list and to explain how a hash map handles collisions. She also asked how I use Git in a team: branches, pull requests and how I resolve a merge conflict.

The last ten minutes were about a REST API I built. She asked what status code I return for a validation error and why.

## HR Interview

Standard questions: strengths, a time I disagreed with a teammate, and whether I was fine with the service agreement.

## Tips

- Revise Python fundamentals, not just problem solving.
- Be ready to design a small database schema on paper.
- If you list Git or REST API on your resume, expect real questions on them.
