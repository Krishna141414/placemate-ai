# Kairos Cloud Labs interview experience - Lakshmi R. (IT, 2026 batch, selected)

(Fictional sample write-up.)

## Online Assessment

Mostly multiple-choice questions on Linux and networking. Examples: what does chmod 754 mean, which command shows running processes, what is the default port for HTTPS, and how many hosts are in a /26 subnet. The scripting problem was to read a log file and print the ten most frequent IP addresses. I wrote it in Python with a dictionary.

## Technical Interview

All scenario-based. "A customer says their website is slow. What do you check?" I went through it step by step: is it slow for everyone, check DNS, ping and traceroute, then CPU and memory on the server with top, then the application and database logs. The interviewer kept asking "and if that is fine, what next?".

Other questions: what happens when you type a URL in the browser, the difference between TCP and UDP, what a load balancer does, and the difference between a process and a thread. On AWS she asked only basics: what EC2 and S3 are, and what a security group is.

## Managerial Round

A role play where the manager acted as an angry customer whose server was down. Stay calm, repeat the problem back, give a time for the next update. He also asked directly whether I was fine with night shifts one week in four.

## Tips

- Use Linux daily for a month before the drive. Commands you have typed are easier to recall than commands you have read.
- Learn subnetting properly.
- In troubleshooting questions, structure matters more than the final answer.
