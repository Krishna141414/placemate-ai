# OrbitPay Fintech interview experience - Ritika B. (ECE, 2026 batch, selected)

(Fictional sample write-up.)

OrbitPay allows ECE, and I want other ECE students to know it is possible. Three of the eight people selected last year were from ECE.

## Preparation

I started data structures in my fifth semester and solved about 300 problems, in Java because the team uses Java. I also did one backend project properly: a REST API for expense splitting with a MySQL database.

## Online Coding Test

I solved one problem fully and the second with a few failing test cases. The cut-off was not announced, but partial solutions were considered.

## Technical Interview

Questions: find the first missing positive number, implement a queue using two stacks, and explain how a HashMap works in Java (hashing, buckets, what happens on a collision, and why equals and hashCode must agree). In SQL I was asked the difference between WHERE and HAVING and to write a query with a self join.

About my project he asked: how do you make sure two people updating the same expense do not overwrite each other? I talked about row versions (optimistic locking).

## System Design Basics Round

Design a notification service that sends SMS and email. Key points I covered: a queue between the API and the senders, retries with a limit, and not sending the same message twice.

## Tips

- ECE students: one solid backend project removes the "why should we take you" question.
- The minimum CGPA is 8.0 and it is checked. A classmate with 7.9 was not allowed to sit for the test.
